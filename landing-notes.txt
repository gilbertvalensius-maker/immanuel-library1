•	Apa keuntungan memisahkan header dan footer menjadi file component tersendiri, dibandingkan menuliskannya langsung berulang-ulang di index.php?
Memisahkan header dan footer menjadi file komponen tersendiri dapat meningkatkan efisiensi pemeliharaan kode melalui penerapan prinsip Don't Repeat Yourself (DRY) untuk mencegah duplikasi. Pendekatan ini memudahkan proses pembaruan karena perubahan pada menu navigasi atau logo cukup dilakukan pada satu file komponen tanpa perlu mengedit seluruh halaman satu per satu. Selain itu, struktur file utama seperti index.php menjadi lebih bersih dan terfokus pada logika maupun konten spesifik halaman tersebut. Langkah ini juga menjaga konsistensi tampilan antarmuka di seluruh aplikasi web sekaligus mempercepat proses pembuatan halaman baru.

•	Perhatikan halaman-halaman admin (Buku, Kategori, Penulis, Pengguna, Profil) pada Bagian 2 - bagian mana pada halaman-halaman tersebut yang mengalami masalah yang sama seperti header/footer sebelum dipisah?
Pada halaman-halaman admin seperti Buku, Kategori, Penulis, Pengguna, dan Profil, bagian yang mengalami masalah duplikasi serupa adalah elemen sidebar atau navigasi samping serta topbar di bagian atas halaman. Selain itu, bagian pemanggilan pustaka luar seperti file CSS di dalam tag <head> serta script JavaScript sebelum penutup </body> juga ditulis ulang secara identik di setiap berkas. Tanpa adanya pemisahan komponen, penambahan menu navigasi baru atau perubahan profil pengguna akan memaksa pengembang memperbarui kodenya secara manual di ke-14 file halaman admin tersebut. Kondisi ini berisiko tinggi menimbulkan ketidakcocokan tampilan dan membuat kode program menjadi sangat sulit untuk dipelihara.
